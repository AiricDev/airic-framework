# Evidence-based reflection

Read the canonical trace and distinguish facts from causal hypotheses. Check whether a rule existed, was routed, was delivered, and was followed. State attribution blind spots and credible alternative explanations.

Produce a focused candidate diff with target kind, target path, base Git commit when available, base content digest, evidence event IDs, semantic change, regression examples, compatibility impact, and validation results. A candidate is not adopted merely because it was produced. Operating Model adoption is a user-reviewed Git commit; domain adoption requires a deployed domain release.
